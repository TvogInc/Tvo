A FEW LITTLE DETAILS

Good questions.
Berry good answers.

Do I need Xcode on my Mac?

No. You just click the buttons aboveto install the apps and sideload them using Sideloadly.

Is Tvo on the App Store?

No. The iPhone build is an unsigned IPA that you sign and sideload yourself using Sideloadly. It is not an App Store download.

What does Tvo need to connect?

Tvo on your Mac and iPhone need to be on the same local network. Add a Gemini API key in the Mac app for voice sessions.
